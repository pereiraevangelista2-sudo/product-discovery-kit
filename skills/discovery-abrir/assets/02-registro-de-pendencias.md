# 02. Registro de pendências do discovery (documento vivo)

**Status:** documento vivo. **Atualizado em:** DD/MM/AAAA.
**Legenda:** [F] fato; [I] inferência; [O] opinião ou sugestão.

IDs: **W** = pendência do responsável pelo discovery; **C** = pendência do Claude. IDs nunca são reaproveitados.

## 1. Situações

- **Aberta:** precisa de ação.
- **Parcial:** parte atendida; a Observação diz o que resta.
- **Condicionada:** depende de aprovação ou etapa futura.
- **Resolvida / Feita:** atendida (o responsável confirma).
- **Contínua:** tarefa permanente.
- **Duplicada:** repete outro item (indicar qual).
- **Registro:** é decisão ou informação, não pendência (mover para o log).
