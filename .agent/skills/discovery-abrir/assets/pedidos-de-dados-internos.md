## 1. Para que serve

Entrevistas dão opinião e contexto. Para decidir entre as opções, também são necessários números e fatos internos. Os pedidos abaixo fecham as lacunas do enquadramento com o menor esforço para quem fornece.

**Princípios:**
- Pedir o **mínimo necessário**, em formato simples (planilha ou exportação).
- **Sem dados pessoais**: por empresa-cliente, não por pessoa. Descrições de chamado sem nomes, e-mails e credenciais.
- Dados parciais já ajudam.
- Registrar **fonte e data de extração**.
